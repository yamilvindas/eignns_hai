# Infection Risk Prediction using Graph Neural Networks

This repository contains the source code for the manuscript **"Epidemiology-informed Neural Networks, Graph Neural Networks, Hospital-Acquired Infections, Infection Risk Prediction"**, in review at *npj Digital Medicine*. It implements various Graph Neural Networks (GAT, GCN, GraphSAGE, STM-GNN, TGN) to predict infection risks across multiple datasets, incorporating both standard and epidemiology-informed neural network architectures.

## Repository Structure

The codebase is split into experiment configurations and the main source code:

```text
.
├── parameters_file/
│   └── [Dataset] (HugCovid, Murcia, SocioPatterns)
│       └── PredHor-[X] (Pred-1, Pred-3, Pred-7)
│           └── [Model_Type] (GAT, GCN, GraphSAGE, STM-GNN, TGN)
│               ├── NotEpidemioInformed/
│               │   └── [config].json
│               └── EpidemioInformed/
│                   └── [config].json
└── src/
    ├── DataManipulation/  # Scripts to generate graph data for each dataset
    │   ├── HugCovid/
    │   ├── Murcia/
    │   └── SocioPatterns/
    ├── Experiments/       # Core execution scripts
    │   ├── GenericExperiment.py     # Base experiment class
    │   └── InfectionRiskPred.py     # Main execution script
    ├── Models/            # GNN architectures and epidemiology-informed models
    └── Utils/             # Loss functions, plotting, and evaluation metrics

```

## Getting Started

### 1. Data Preparation

Before running experiments, the raw data must be converted into graph structures. Navigate to src/DataManipulation/ and run the scripts corresponding to the target dataset (HugCovid, Murcia, or SocioPatterns) to generate the necessary graph data.

### 2. Running an Experiment

All models and experiments are launched from the root directory using the InfectionRiskPred.py script. You dictate the exact dataset, prediction horizon, and model architecture by passing the appropriate JSON configuration file from the parameters_file/ directory.

Example Command:
Bash

python src/Experiments/InfectionRiskPred.py \
    --parameters_file parameters_file/InfectionRiskPred/Murcia/PredHor-7/GAT/NotEpidemioInformed/NotEpidemioInformed.json

Outputs:
Running an experiment automatically generates a results/ folder in the root directory. The hierarchical structure of this folder separates Hyperparameter Optimization (OPTUNA) from final model training (SimpleTraining).

Note: The complete results folder generated by these scripts (including trained models, HDF5 evaluation files, and Optuna databases) is over 12 GB and is hosted separately on Zenodo.

### 3. Analyzing and Visualizing Results

The src/Utils/ directory contains tools to evaluate model performance, recreate figures, and analyze the learned epidemiological parameters.

A. Generate Primary Manuscript Results (plot_results_for_paper.py)
Generates the primary visualizations and LaTeX-formatted tables used in the publication by aggregating across all models for a given dataset.

    Target: The main dataset folder containing the prediction horizons (e.g., results/[DatasetName]).

    Flags: Use --force_metrics_computation to overwrite existing cached metrics.

Bash

python src/Utils/plot_results_for_paper.py \
    --main_results_folder results/InfectionRiskPred/Murcia \
    --force_metrics_computation

B. Analyze Individual Experiment Metrics (plot_metrics.py)
Computes and plots losses, ROC curves, PR curves, and threshold sweeps for a single experiment's result folder.

    Target: A specific experiment folder inside SimpleTraining/ or OPTUNA/.

    Flags: --plot_loss, --plot_metrics_evolution, --analyze_multiclass_failure, --force_metrics_computation.

Bash

python src/Utils/plot_metrics.py \
    --results_folder results/InfectionRiskPred/Murcia/PredHor-7/SimpleTraining/GAT_NotEpidemioInformed/ \
    --plot_loss \
    --plot_metrics_evolution

C. Evaluate Epidemiology-Informed Parameters (learned_params_metrics.py)
Extracts the epidemiological parameters (e.g., beta, gamma) learned dynamically by the epidemiology-informed architectures (like STM-GNN with ODE-NSP) and compares them against ground truth calculations via cosine similarity, optimal scaling, and error norms.

    Target: A specific experiment folder for an EpidemioInformed run.

Bash

python src/Utils/learned_params_metrics.py \
    --results_folder results/InfectionRiskPred/Murcia/PredHor-7/SimpleTraining/STM-GNN_ODE-NSP/

D. Population-Level Evaluation (population_level_metrics.py)
Calculates aggregated predictive metrics across the entire population and plots the predicted epidemic evolution compared to the actual state transitions (SIR, SEIR, or SEIRD-NS models depending on the dataset).

    Target: A specific experiment folder.

Bash

python src/Utils/population_level_metrics.py \
    --results_folder results/InfectionRiskPred/Murcia/PredHor-7/SimpleTraining/GAT_NotEpidemioInformed/
